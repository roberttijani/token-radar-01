A deterministic, zero-network **Token Launch Radar** and offline Light-Editorial dashboard built in pure Node.js 22+ TypeScript (standard library only) for make.fun's `token-radar-01` bounty.

## What It Computes

From the sealed DefiLlama snapshot (`758` protocols with TVL >= $5M as of `2026-11-14`), `main.ts` separates live-token protocols (`416`) from protocols recording no token (`342`), applies the official exclusion criteria uniformly (no hardcoded protocol names), and ranks **198 pre-token candidates**:

- **40 / 40 Watchlist protocols** (100% watchlist coverage, TVL >= $50M)
- **158 Early Finds** (pre-token protocols below the $50M floor down to $5M TVL)
- **92 Live Comparables** (non-excluded protocols with positive `mcap_usd` and TVL >= $5M used strictly for out-of-sample model calibration)

Every implied value is recomputed client-side in `dashboard/app.js` directly from raw snapshot figures and verified against `board.json` (`198 / 198` exact matches).

## Two-Stage Empirical Bayes + Ridge Valuation Model (LOOCV)

Rather than applying a flat TVL multiplier or hardcoding protocol names, `lib/model.ts` calibrates a log-linear valuation model (`eb-ridge-loocv-v1`) on the 92 live comparables via Leave-One-Out Cross-Validation (LOOCV):

1. **Stage 1 — Empirical Bayes Category Shrinkage:** Computes global log-multiple median ($\mu_0 = -1.4729$, base multiple `0.2293x`) and shrinks each category's median multiple toward $\mu_0$ by $\frac{n_c}{n_c + \lambda_c}$ ($\lambda_c = 4$).
2. **Stage 2 — Regularized Ridge Regression ($\lambda_r = 5$):** Fits category-residualized log-multiples against five standardized snapshot features: log-TVL size elasticity, 7-day TVL growth momentum, linear and quadratic protocol age maturity, and multi-chain breadth, with an automatic anti-overfitting fallback guardrail.
3. **Uncertainty Bands:** Empirical LOOCV residual quantiles (`P25`–`P75`) produce calibrated `implied_low_usd` and `implied_high_usd` intervals for every candidate.

## 7-Step Net-to-the-Dollar Farm Plan Engine

`lib/farm.ts` selects the lowest-gas chain in each protocol's `chains` list (tie-break ASCII) and builds a deterministic 7-step execution ledger with strict penny-level reconciliation (`|sum(steps) - total_cost_usd| < $0.01`):

- **Cost Accounting:** Per-step gas (chain gas unit × step gas multiplier), category-specific protocol/swap fees (10–55 bps), and risk-free opportunity cost (4.5% APR over the 60–120 day holding window).
- **Expected Value & Viability Tiers:** Computes Gross EV (5% airdrop pool share / 70% eligible TVL × age-based launch weight), Net EV, Low/High Net EV, Break-Even Capital, and viability classification (`VIABLE`, `WHALE_ONLY`, or `NEGATIVE`). At the default `$2,500` capital: `72` Viable, `14` Whale-Only, `112` Net-Negative.
- **Interactive Capital Simulator:** The offline dashboard lets readers vary farming capital from `$500` to `$50,000` and live-recalculates every protocol's 7-step ledger, break-even, and viability tier without network calls.

## Run It

Requires Node.js 22.18+ (standard library only, zero `npm install`, zero network):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input token-radar-01-kit/input/snapshot.json
```

Outputs written to `out/`: `board.json`, `data.js`, `dashboard/`, `screenshots/`, and `dossier.json` (generated by the unchanged `vendor/makefun-board.ts`). Open `out/dashboard/index.html` directly in any browser with no network access.

## Disclaimer

DefiLlama's snapshot record is not proof of token absence; protocols listed on the board simply record no token in the sealed snapshot. All implied valuations, uncertainty bands, and farm expected-value figures are deterministic statistical estimates for research and comparison purposes only—not financial advice or a prediction of whether or when any protocol will issue a token.
